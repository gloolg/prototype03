Multi-Source Transfer

Multi-Source Operations

How it works

Multi-source mode lets you combine balances from multiple networks into a single delivery. For example: send 500 tEQUI to Network D by contributing from Networks A, B, and C simultaneously.

Key points:

  • You sign N separate MetaMask transactions — one per source network
  • Each transaction sends tEQUI to the IT-EOA on that source network
  • Delivery happens only after all source transactions are confirmed
  • The operation has a 5-minute window to collect all sources
  • If the window expires or delivery fails, each source is eligible for individual refund via the admin panel
All-or-nothing: delivery to the recipient only happens when every declared source is received. If not all arrive in time, funds can be returned to each sender individually.

Disable Multi-Source Operations

What changes

After disabling:

  • The Transfer form returns to single-source mode only
  • Initiating new multi-source transfers will not be available
  • Already-started operations with COLLECTING status continue processing independently — disabling this does not cancel or affect them in any way

You can re-enable multi-source operations at any time using the same button.

Wallet signature error

If you cancel, any tokens already sent to the IT-EOA on confirmed steps will be returned to their respective wallets and networks.
